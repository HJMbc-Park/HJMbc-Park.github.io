# 편평사마귀·피부 질문노트

박서연 한의사(화접몽한의원 부천점 대표원장)의 피부 질문 정보 노트입니다. GitHub Pages로 운영합니다.

## 새 글 올리는 법

1. `_posts` 폴더를 엽니다.
2. `Add file` → `Create new file`을 누릅니다.
3. 파일 이름을 `날짜-영문-주소.md` 형식으로 씁니다. 예: `2026-10-20-flat-wart-shaving.md`
4. 아래 틀을 붙여 넣고 내용을 바꿉니다.
5. `Commit changes`를 누르면 1~2분 뒤 사이트에 올라갑니다.

```
---
layout: post
title: "환자가 묻는 질문 그대로 제목"
description: "검색 결과에 보일 한두 문장 설명"
date: 2026-10-20 09:00:00 +0900
answer: "질문에 대한 결론 두 문장"
faq:
  - q: "자주 묻는 질문"
    a: "답변"
---

## 소제목

본문
```

## 지켜야 할 것

- 정보 글만 올립니다. 예약 버튼, 가격, 이벤트, 상담 유도 문구는 넣지 않습니다.
- 완치, 재발 없음, 100%, 다른 병원·치료법과의 비교, 환자 후기는 쓰지 않습니다.
- 네이버 블로그 글을 그대로 복사하지 말고 질문-답 형식으로 새로 씁니다.
